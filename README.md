# **Capstone-2**

## 🚀 Project Overview

**Capstone-2** is a modern front-end web application built using **React** and **Vite**. It was developed as part of a capstone or portfolio project to demonstrate web development skills including responsive UI design, component-based architecture, and deployment readiness. The app is also configured for fast development with live hot-module reloading and optimized builds. ([GitHub][1])

This repository includes all source code, setup configurations, and deployment settings needed to run the application locally and host it on platforms like **Vercel** or **Netlify**. ([Vercel][2])

## 🛠️ Getting Started

### Prerequisites

Make sure you have the following installed:

* **Node.js** (version >= 14)
* **npm**

---

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/HanzalaParacha763/Capstone-2.git
   cd Capstone-2
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. Open your browser and go to:
   `http://localhost:5173` (default Vite port)

---

## 📦 Build & Deployment

### Create a production build

```bash
npm run build
```

After building, your app will be optimized in the `dist` folder and ready for deployment.

### Deploying

This project is ready to be deployed to platforms like **Vercel** or **Netlify**. Simply connect your GitHub repo, select this project, and deploy — Vercel will automatically detect the Vite setup. ([Vercel][3])
